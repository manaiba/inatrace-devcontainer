# Format:
#   <git-url>            [optional-target-dir]
#
#   <git-url>    : SSH (git@github.com:org/repo.git) or HTTPS URL.
#   target-dir   : optional folder name created under src/. Defaults to the
#                  repo name (URL basename without the trailing ".git").
#
# Examples:
#   git@github.com:org/repo.git
#   https://github.com/org/other.git   other-renamed
#

#

#       git@github.com:manaiba/inatrace-backend.git
